Добавлять материалы — просто

Заполните карточку, загрузите изображение и укажите ссылку на опубликованную игру, доску или другой материал. Все записи сохраняются в черновике этого браузера. По завершении скачайте обновлённый catalog-data.js и замените его в репозитории GitHub.

Важно. Этот редактор не меняет публичный сайт сам: GitHub Pages — статический хостинг. Для публикации изменений нужно заменить файл catalog-data.js в GitHub. Фото, загруженное с компьютера, редактор встроит в карточку автоматически; отдельная загрузка изображения не потребуется. Сам HTML-материал нужно разместить на GitHub Pages отдельно.

1–2 предложения о реальной учебной задаче, без рекламных формулировок.

Для материалов, размещённых вместе с витриной: materials/название.html. HTML-файл необходимо заранее загрузить в папку materials в GitHub. Можно вставить полный URL уже опубликованного материала.

Или загрузите изображение с компьютера — оно будет уменьшено и встроено в карточку.

Как опубликовать добавленный материал

  1. Загрузите готовую HTML-игру в папку materials репозитория GitHub. Если материал уже опубликован на другом сайте, достаточно его настоящего URL.
  2. Откройте editor.html, нажмите «Новая карточка», заполните поля и загрузите изображение.
  3. Нажмите «Сохранить карточку», затем «Посмотреть черновик». Проверьте заголовок, описание, фильтры и кнопку «Открыть».
  4. Нажмите «Скачать обновлённый каталог». Получится файл catalog-data.js.
  5. Загрузите этот файл в корень репозитория GitHub с заменой старого. Сохраните изменения (Commit changes). GitHub Pages покажет обновление после публикации.

Примечание: сохранение в браузере — только черновик на вашем устройстве. Для постоянной публикации всегда скачивайте catalog-data.js.
