Как работать с конструктором

Один список слов — пять интерактивных орфографических заданий. Всё настраивается слева, результат отображается справа.

  1. Подготовьте список слов

    В левом меню укажите название и класс. Выберите тип орфограммы. В поле «Ваш список слов» введите по одному слову на строке и нажмите «Создать задания из слов». Или сначала попробуйте готовый пример.

  2. Отметьте или проверьте нужные буквы

    Ниже списка нажмите на слово, затем выделите в нём букву или несколько букв, над которыми будет работать ученик. Для другого слова повторите действие.

  3. Дополните настройки для нужных заданий

    Для «Исправь ошибку» впишите ошибочный вариант, для «Распредели слова» — название группы, для «Объясни написание» — проверочное слово и образец объяснения. Необязательные поля можно оставлять пустыми, если такой формат вам не нужен.

  4. Посмотрите результат справа

    Переключайте пять вкладок над рабочим холстом, чтобы проверить, как выглядит каждое упражнение. При необходимости вернитесь к настройкам слева.

  5. Скачайте задания для ученика

    Выберите «Все 5 заданий» либо «Только текущее», затем нажмите «Скачать упражнение». Полученный HTML откроется в браузере без интернета. Его можно отправить ребёнку или открыть на онлайн-занятии.

Полезно знать. Для удвоенных согласных конструктор сам находит пары букв и предлагает варианты; для остальных тем педагог отмечает орфограммы вручную. Результат всегда нужно проверить. Свободные объяснения ребёнка сравниваются с образцом учителя, а не оцениваются автоматически.
